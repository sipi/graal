# Licensing and code provenance

Graal was written under an employment contract and is distributed under CeCILL 2.1: porting its code would create a derivative work under CeCILL, while re-implementing algorithms from publications avoids that. This page also records the licences of the other engines and libraries we may use or learn from. To be validated by legal counsel.
