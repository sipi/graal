# VLog and Rulewerk

VLog (C++, column-oriented Datalog and existential-rule engine) and Rulewerk (its Java API) from the Krötzsch group are Nemo's predecessors. They introduced the Datalog-first restricted chase in practice and restraint/reliance-based scheduling. Legacy today.
